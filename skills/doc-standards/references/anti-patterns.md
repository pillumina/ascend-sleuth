# 反例清单：篇章层

> 这份清单只收**篇章层**的反例——结构、开篇、状态、论证、出处。词句层的反例在 `docs/spec/writing-norms.md` §1（43 条，每条带反例），那里是判定口径的权威，本文件不与它重复。
> 每条三段：症状（怎么认出来）、为什么坏、怎么改。带仓库路径的例子是真实病灶。

## 一、结构

### 1. 开篇是杂物间

症状：第一个标题之前连着五段以上引用块，术语表、相邻文档的分工、方法论对比、原则编号全挤在那里。本仓实例：`docs/mechanism/pipeline.md` 的开篇是十段连续引用块，把「写给谁」「覆盖什么」「三个相邻文档的分工」「原则十一」「四个蓝图新名词」都塞在第一个标题之前。
为什么坏：读者此时还读不懂这些术语，读到 §1 时已经要同时记住十个东西。第一屏的作用是让读者判断「要不要往下读」，不是抢先给结论。
怎么改：第一屏只留那五件事（这是什么 / 为什么值得读 / 范围 / 读者与前置 / 何时不必读）。术语表挪到首次需要它的那一节；相邻文档的分工挪到文末；方法论对比单独成节放文末。

### 2. 标题看不出要做什么

症状：标题是名词短语——「概述」「简介」「使用场景」「工作原理」；或者用 -ing 形式。
为什么坏：读者扫标题时是在找「我要做的那件事在哪一节」，名词短语答不出来。
怎么改：操作类标题写成「主动词 + 对象」（配置采集超时、回放一次失败的诊断）；概念类标题用名词，用 -ion 不用 -ing；确实要写「这是什么」的节，标题里带上那个东西的名字。

### 3. 一页兼两职

症状：规范条文里夹操作步骤；操作指南里用整节解释机制；机制说明里塞了一串命令。
为什么坏：两类读者的读法不同。要动手的人会被解释挡住，要理解的人会被步骤打断。具体塌方有七种：两边的读者都受损；两类需求同时落空；结构自我复制地塌下去（下一层照抄上一层，越写越乱）；标题与内容对不上；可扫读性下降；维护代价耦合（改一处要顺着整条路径改）；检索时归位失败。本仓 `docs/` 的六层就是按这个分的，混装等于把层的划分作废。
怎么改：主干留一类，另一类链出去。操作指南里必须解释概念时，用一句话加一个链接。

### 4. 零信息小节与纯链接页

症状：某节只有一两句话，或者整篇只有一串链接。FAQ 页也属这类。
为什么坏：一两句话的节让目录虚胖，读者点进去发现是空的；纯链接页没有自己的内容，只会过期；FAQ 按问题堆叠，内容互不相关、难排序、难检索，最后一定腐烂。
怎么改：撑不到一个小节的，并进相邻节。纯链接页改成一句「这些外链各自解决什么」放正文里。FAQ 拆进它本该属于的类型。

### 5. 篇幅失控

症状：一节套七个小节，一段十二句，末尾「继续读」列十条。
为什么坏：读者一次能带走的东西有上限，超出部分等于没写。
怎么改：一节不超七个小节，一段不超六句，出边不超五条。超了就拆节——注意，**不是设字数上限**，本规范不规定一篇文章多少字。

## 二、论证

### 6. 方案先行

症状：开头直接讲怎么做，不写为什么要做。
为什么坏：没有动机的提案，评审只能就实现论实现，看不出这个改动该不该做。
怎么改：Motivation 放最前面，只写问题与代价，不写方案。方案留到下一节。

### 7. 没有「不做什么」

症状：只写目标，范围边界靠读者猜。
为什么坏：边界不明，评审会在范围上反复拉扯，同一条评论出现三轮。
怎么改：Non-Goals 单独成节，写成「这本来可以是个目标，本次明确不做」。写了「不做」的，就要能被引用为拒绝后续要求的依据。

### 8. 替代方案是稻草人

症状：Alternatives 一节列了一两个明显更差的方案，一句话否掉。
为什么坏：替代方案这一节的价值全在「代价对比」。只列稻草人等于没写，读者会怀疑作者根本没比较过。
怎么改：每个替代方案写清它好在哪、代价是什么、为什么不选。选不出来的（确实只有一条路）就明说没有替代方案，不要凑数。

### 9. 只列好处不列代价

症状：后果一节全是正面词；有人写「本方案没有明显缺点」。
为什么坏：「没有缺点」按缺陷处理——它说明作者没想清楚，或者不敢写。
怎么改：后果分条写，每条写成「好，因为……」「坏，因为……」。写不出坏的，去问实现它的人。

## 三、状态与留痕

### 10. 状态腐烂或缺失

症状：文档没有状态字段；状态散在正文里；同一个标题下同时躺着已完成和构想中的内容。本仓实例：`docs/mechanism/pipeline.md` 把「已落地 / 蓝图 / 已否决」混排在同一层；`docs/adr/` 现有的记录只有「结论 + 为什么 + 被否决的替代方案」三段，没有状态与后果。
为什么坏：读者分不清哪句是现在的系统，哪句是设想。这类文档过一段时间一定错，而错得看不出来。
怎么改：头部放且只放一个状态字段，取值来自一个固定集合。区分「已批准」与「已落地」。计划类文档里每个条目标自己的状态，不放依赖读者推断。

### 11. 改写已经批准的决策

症状：直接编辑一条已批准的记录，把当初的选择改成现在想选的。
为什么坏：历史被抹掉之后，下一个人会重新提出同一个被否掉的方案，而没有人记得为什么否掉。
怎么改：已批准的记录不改。要变就新开一条，新条写 supersedes，旧条写 superseded by，两头都写全。被拒的文档不删，要写拒绝理由。

### 12. 已决与臆测同段

症状：一段话里前半句是定论，后半句是「也许可以」。
为什么坏：读者按定论执行，然后发现那条根本还没定。
怎么改：未决内容集中到一节的「未决问题」里，节首声明这一节不构成实现依据。已定的写「是」，未定的写「未定」。

## 四、改写时最容易翻车的

这三条只在改写已有文档时出现，而且都是改完看着更顺、实际更坏。

### 13. 情态升格

症状：改写时把「可能会」写成「会」，把「建议」写成「必须」，把「在多数情况下」删掉。
为什么坏：原文的模糊是内容，不是文风问题。删掉模糊等于凭空给出一个更强的承诺。
怎么改：「可能 / 也许 / 在某种情况下」照写。这条也适用于任何机械检查——**检查工具永不标记情态**。

### 14. 为求短删掉安全条件

症状：为了把句子压到规定长度，删掉前置检查、边界条件、失败时的处理。
为什么坏：读者照着做会踩进去，而且看不出是自己漏了还是文档没写。
怎么改：安全条件优先于句长。压不下来就拆句或分段，不删条件。

### 15. 只改句子不改结构

症状：一篇结构散掉的文档，从头到尾润了一遍句子，节还是那些节，顺序还是那个顺序。
为什么坏：读者的问题在于找不到结论，不在于句子难读。改完还是找不到。
怎么改：按 `SKILL.md`「改一篇已有的文档」那一节的顺序来——先定类型，再动骨架，最后才改句子。

## 五、图与事件文档

### 16. 图脱不开正文

症状：图里画了什么全靠正文解释；图后面没有说明段落；箭头只写「调用」「使用」，看不出传的是数据还是控制。
为什么坏：读者扫图是为了快速拿到结构，图读不懂就等于没有图，还多占一屏。关系语义缺失时，图只能证明「这几个东西有关」，不能证明「它们怎么连」。
怎么改：图上每个元素给类型与一句职责，关系线写清传什么、调什么；配图例；图后写一段「这张图里值得注意的地方」。用 Mermaid 写进 Markdown，不交二进制图片。细则见 `type-catalog.md` 附录。

### 17. 复盘用词比事实更强

症状：不是全面不可用写成「全站不可用」；一次误诊写成「系统故障」；「可能」写成「导致」。
为什么坏：复盘是下一次改动的依据，用词一强，行动项的优先级和范围就跟着错。
怎么改：影响按实际范围写，量化不了就写「无法量化」；时间线只写事实与来源。本仓还要分清是这一类 case 归错了，还是执行这条 case 时错了，两者改法不同。

### 18. 时间线没有数据来源

症状：时间线每行只写时间与结论，不写这条是从哪看来的。
为什么坏：事后没人能核对，有争议时只能靠记忆，也看不出哪一段是推断。
怎么改：每行末尾给来源——trace 路径、命令、日志片段。写不出来源的那一行，明说它是推断。

## 六、出处与来源

### 19. 论断没有出处

症状：写「业界共识」「实测更优」「有观点认为」，或者抛出一个数字不说从哪来。
为什么坏：读者无法核对，也判断不出这条什么时候会失效。规范与机制文档是后续改动的依据，凭印象写的结论会让下一个人按错的前提动手。
怎么改：每个论断指回可核对的东西——`文件:行号`、命令与输出、issue 或论文链接。指不回去的，标成推测或删掉。

### 20. 同一件事抄了两遍

症状：同一张表、同一段说明在两个文件里各有一份，更新时只改了其中一处。
为什么坏：两份副本必然漂移，读者不知道哪份是准的，改的人也不知道该改哪份。
怎么改：留一处为准，另一处改成链接。确实必须重复的（例如 skill 要自包含到「没有 `docs/` 也能执行」），必须写明以哪一份为准、以及怎么核对两份没有漂。

## 提交前自查

写完或改完，逐条过：

- [ ] 类型定对了吗？一篇只装一件事吗？
- [ ] 骨架里的小节齐吗？顺序对吗？
- [ ] 第一屏只有那五件事吗？有没有出现读者此刻还读不懂的词？
- [ ] 每节第一句是结论吗？
- [ ] 「不做什么」与「为什么没选别的」写了吗？被否决的方案给了代价吗？
- [ ] 状态字段在头部、取值合法吗？已落地与已批准分开了吗？
- [ ] 一段一个主题、不超六句？
- [ ] 图有文字说明吗？图能脱离正文读懂吗？有图例、是用 Mermaid 写的吗？
- [ ] 外部讨论在文末吗？正文里有没有只在后半段才定义的词？
- [ ] 复盘的影响用词比事实强吗？时间线每行有来源吗？行动项给的是判据而不是日期吗？
- [ ] 每个论断指回来源了吗？指不回去的标成推测了吗？
- [ ] 该链接的地方没有抄第二份吗？必须抄的写明了以哪份为准吗？
