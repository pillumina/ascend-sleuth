# src_fetch（按版本取源码 / 源码位置发现）

`/diagnose` 步骤 5 深度排查走到源码分析时的入口契约。**SKILL.md 只写"什么时候用"**，这里的展开是"命令行怎么写、退出码怎么读、拿不到时怎么问"。

## 两种形态

| 形态 | 命令 | 用在什么时候 |
|---|---|---|
| 已知仓 | `python3 scripts/src_fetch.py <repo> --ref <tag\|commit>` | 报错已经指向具体仓（`--list` 看已知表） |
| 不知道仓 | `python3 scripts/src_fetch.py --find "<报错签名>" --ref <版本>` | 只知道接口前缀与算子名（`aclnn*`、`Hccl*`、`ge::`、`aclrt*`…） |

辅助开关：`--offline`（`--find` 只给候选、不联网）、`--self-test`（校验签名→候选仓匹配表）、`--list-versions`（本地已有版本，命中即复用）、`--url`（私有/内网仓）、`--dest`（换缓存根，默认主检出 `src-code/`）。

## 缓存布局

`src-code/<org>/<repo>/<解析后的 ref>/`——**一个版本一个目录**，各版本物理隔离（并发诊断各读各版本，不存在"别人 checkout 走了我正在读的版本"）。缓存根锚在**主检出**，同一克隆的所有 worktree 共读共写。版本目录名与 case 的 `source_ref.ref` 是同一个 token，案例与源码互查不用转换。

## 退出码就是契约

调用方只看退出码与 stdout 末行，别看输出里的路径：

| 码 | 含义 | stdout 末行 | 该做什么 |
|---|---|---|---|
| 0 | 已在本地产出该 ref 的树并核对通过 | 版本目录绝对路径 | 直接 grep 那个目录 |
| 2 | 用法问题（未知仓无 `--url`、`--find` 没给签名…） | 失败声明 | 看 stderr 的修法 |
| 3 | ref 解析不了（tag 名不同，输出里有可用 tag）**或**候选 ≥2 未定仓（输出里有候选表） | 失败声明 | 前者按列出的 tag 重试；后者问一句（见下） |
| 4 | 拉取失败（网络/私网/凭据）或拉到的提交与 ref 不符 | 失败声明 | 可达地址用 `--url`；镜像内代码按冻结 commit 取 |
| 5 | 本地有该版本目录但核对不通过 | 失败声明 | 确认是它才加 `--force` 重拉 |

**非零 = 没拿到这个版本的源码。** 不要拿本地其他版本的目录去读（那是错版本的证据），也不要拿 web 搜索结果当源码（搜上游 issue/PR 状态是另一回事）。

## `--find` 怎么读结果

1. 脚本按签名里的**接口前缀**与**算子名**给带理由的候选（默认前 3 个，按命中分排序）。
2. 候选逐个试该 ref：**只有一个能解析 → 自动取回（exit 0）**。
3. 多个候选都能解析 → exit 3，交回候选表与各自的解析结果。**同名 tag 不构成定位证据**（CANN 各仓共用同一套发布号）。
4. 只命中**公共前缀**（`aclnn xxx` 没给算子名）→ 命中的是**兜底候选**，仍 exit 3：补算子名/接口名重试，或问一句。
5. 已经确定是哪个仓 → 把仓名写在签名后面（`--find "<签名>" cann/ops-nn`），**以它为准**，候选表只作对照。

**候选 ≥2 或兜底时问的那一句**（绑定在 `collect-gates.yaml` 的 `source-location` 闸门，探询纪律同其它闸门：只问一次、只问一句）：
「这个报错在你们那的 CANN 安装目录里落在哪个子目录？」——附上候选表让他回编号。装目录的子目录名就是仓名，比任何描述都准。

**不要向工程师要 URL**：组织仓库清单是可枚举的事实（一条匿名 API），把它变成别人的记忆负担是把可复现的一步退回给猜。只有候选都试不通、或仓是私有的，才要地址。

## 维护匹配表

签名 → 候选仓的映射是**数据**，在 `scripts/src_fetch.py` 的 `ORG_SIGNATURE_REPOS` / `ORG_SIGNATURE_KEYWORDS`：每个仓一组关键词（`any_of` / `all_of`）、判别词（`discriminators`）、主候选词（`primary`）与兜底标记（`fallback`）。仓本身是哪个、属于哪一层，见先验层 `references/software-facts/cann-source-location.yaml`。

改完必须跑 `python3 scripts/src_fetch.py --self-test`：关键词含大写、仓名写错、真实签名不再命中，都只表现为**静默零候选**（看起来像"上游没有这个仓"），自测是唯一能让它响亮失败的地方。
