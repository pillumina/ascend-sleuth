# A5 (950) 平台背景

最新架构，大规模训练主力。FP8 和超大规模 EP 是 A5 独有问题的高发区。

## 关键特性

- **FP8**：**FP8 精度问题只在 A5 出现**（衰减、溢出、算子精度退化）。FP8 相关 case 的 `platforms` 只含 A5
- **大规模 EP**：`world_size >= 64` 的 all_to_all 通信瓶颈是 A5 高频问题（见 canonical sample `MSLLM-EP-HANG-001`）
- **HCCL**：与 A3 近似，但 buffer 需求因规模更大而更敏感

## 建库注意

- FP8 case 必须独立 `platforms: ["A5-950"]` 分支
- 大规模通信 case 的 `rank_selector` 常用 `coordinator` 或 `by_topology`（不能只查 rank 0）
