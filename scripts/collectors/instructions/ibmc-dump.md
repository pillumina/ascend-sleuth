# iBMC 一键收集（带外日志）

## 用途

从目标服务器的 iBMC 导出一键收集包，交给 `ibmc_analyzer` 判断服务器硬件健康、当前告警与带外事件。采集在 BMC 侧完成，不需要登录业务 OS，也不在业务 OS 上安装软件。

## 适用环境

- 能访问目标服务器 iBMC 管理网的浏览器或命令行。
- iBMC 账号具备「一键收集」或「日志导出」权限。
- 不同 iBMC 版本的菜单名可能不同，以现场界面为准。

## 权限与影响

- 需要 iBMC 管理员或具备日志导出权限的账号。
- 一键收集读取 BMC 日志、传感器与硬件状态，通常不影响业务 OS 与训练/推理任务。
- 导出时间取决于 BMC 日志量，常见为几分钟。
- 不经过公网，不上传到 Sleuth。

## 步骤

1. 登录 iBMC Web。
2. 进入「维护诊断」→「一键收集」，选择完整日志导出。
3. 下载压缩包并解压，确认包含 `dump_info/` 目录。
4. 多台机器分别导出；把每台机器的 `dump_info/` 目录或压缩包放在不同子目录，便于集群对比。
5. 把结果交给 `ibmc_analyzer`。

```bash
python3 scripts/analyzers/cli.py run ibmc_analyzer --inputs "<dump_info 目录或压缩包>"
```

## 客户需要返回

- 含 `dump_info/` 的压缩包，或解压后的 `dump_info/` 目录。
- 多机时每台机器一份，保留机器名或节点名。

## 敏感信息

收集包含序列号、管理网 IP、账号登录记录、硬件与传感器读数。按客户要求脱敏后再流转；不要只改文件名当作脱敏。

## 注意

- 缺文件时 `ibmc_analyzer` 会写进 `missing`，不要把「这项没数据」读成「这项正常」。
- 当前告警与 SEL 历史要分开看；SEL 里的历史掉电不等于当前故障。
