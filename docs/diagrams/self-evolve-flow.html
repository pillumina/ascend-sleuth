自演进机制全流程

系统每次干活后自动找改进点 → 改 + 验证 → 人把关 → 合入生效 → 下次更准（循环）

改进从哪来：不专门“跑改进”

  • 每次诊断 / 沉淀 / 拉取干完活，收尾自动瞄一眼
  • 信号例：同类问题反复查不到（缺知识）、某步老错（修流程）
  • 没信号就一行带过——不为改进而改进

改对才算数：验证是硬门槛

  • 每张卡自带“怎么验证”：真实已解决 issue 对照，或回放历史测试
  • 验证不过 → 如实记“不行”并丢弃（诚实记录也给人看）
  • 改流程影响所有诊断，验证比改知识更严

人在哪把关：审批 + 季度回顾

  • 一批改进攒一个 PR，人按卡审：整体合入或单独打回
  • 涉及路由 / 结构的高风险改动需双签
  • 每季度人审一次流程本身：信号准不准、要不要调参数
